A clean, distraction-free dashboard for tracking habits, goals, and daily reflections. Built with Next.js and Supabase for real-time sync across devices.

## Features

- Daily habit tracking
- Goal progress visualization
- Quick journal entries
- Dark mode support
- Mobile responsive

## What I Learned

This was my first project using Supabase, and I was impressed by how quickly I could get authentication and real-time features working. The hardest part was designing a UI that felt calm instead of overwhelming.

I also learned the importance of progressive disclosure—hiding advanced features until needed keeps the interface clean for daily use.
