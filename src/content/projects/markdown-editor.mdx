Building a writing tool that prioritizes focus over features. Saves everything locally using IndexedDB, with optional sync coming later.

## Current Status

The core editor is working, with live markdown preview and local storage. Still working on:

- Export to PDF/HTML
- Custom themes
- Keyboard shortcuts
- Cloud sync (maybe?)

## Design Philosophy

Most writing apps are bloated with features you don't need. This one does one thing: helps you write in markdown without distractions. No accounts, no cloud lock-in, just a text editor.

Inspired by iA Writer and Typora, but simpler.
